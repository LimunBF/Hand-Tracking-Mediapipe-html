# Hand Tracking MediaPipe

Demo iseng hand tracking berbasis browser memakai MediaPipe Hands dan p5.js.

## Fitur

- Deteksi hingga dua tangan
- Hitung jari dan kenali beberapa gestur
- Efek Laser, Riso Plane, dan Both
- Efek partikel saat ujung jari bersentuhan

## Menjalankan

```bash
python3 -m http.server 8123
```

Buka `http://127.0.0.1:8123`, lalu izinkan akses kamera.

Internet diperlukan untuk memuat MediaPipe dan p5.js dari CDN.
